# Instructions for this knowledge store

Help keep this folder useful for collecting, organizing, summarizing, and reusing personal and professional knowledge.

## Organizing content

- Organize notes, documents, images, and text into the appropriate existing category.
- If the right category is unclear, ask the user before moving or filing the content.
- Do not create a new folder unless the user confirms first.
- When organizing content, update the relevant `index.md` file or files so the content can be found.
- Prefer Markdown for summaries and indexes.

## Protecting files

- Never delete an original file without asking the user first.
- Never overwrite an existing file without asking the user first. Create a separate file when a new version is needed, or ask how the user wants to proceed.
- Preserve original content when creating summaries or converted versions.

## Writing

- Use clear, simple language and descriptive filenames.
- Keep summaries focused, and include source links or context when useful.
- Read relevant files before editing or organizing them, and preserve their meaning.
